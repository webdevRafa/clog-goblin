# Clog Goblin Plumbing Co.

A polished, responsive, multi-page React demonstration for a fictional
satirical plumbing brand. The service information is practical; the mascot is
deeply unimpressed.

## Local development

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run build
```

## Image workflow

The seven original `cartoon-*.png` illustrations are preserved in
`src/assets`. Optimized WebP derivatives are used by the application.

```bash
npm run optimize:images
```

## Important demonstration notice

Clog Goblin Plumbing Co. is fictional. Phone numbers, email addresses, service
areas, office hours, reviews, business claims, policies, and the estimate-form
submission are placeholder content. Replace and review them before adapting the
site for a real operating business.
